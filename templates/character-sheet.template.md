Create a professional character creation sheet / character reference board in a clean modern editorial layout.

The final image should be a polished landscape presentation sheet with a bright white or very light neutral background, minimalist design, clean alignment, and bold sans-serif typography.

CHARACTER:
Name: [CHARACTER NAME]
Tagline: [SHORT TAGLINE]
Gender: [GENDER]
Age Group: [AGE GROUP]
Ethnicity: [ETHNICITY]
Build: [BODY TYPE / BUILD]
Hair: [HAIRSTYLE / COLOR / LENGTH]
Eyes: [EYE COLOR]
Style: [FASHION STYLE]
Accessories: [GLASSES / JEWELRY / WATCH / ETC.]

PERSONALITY SUMMARY:
[2–4 sentence short summary of the character’s personality, values, vibe, and presence.]

CHARACTER DESCRIPTION:
[Longer paragraph describing who the character is, how they behave, what kind of energy they bring, and what makes them distinctive.]

VISUAL REQUIREMENTS:
Show the same exact character consistently in 4 reference views:
1. Front View
2. Three-Quarter View
3. Side Profile
4. Full Body

The character must remain visually identical across all views:
- same face
- same hairstyle
- same clothing
- same accessories
- same body proportions
- same age and ethnicity

LAYOUT REQUIREMENTS:
- Large bold character name prominently displayed at the top left
- Short tagline beneath the name
- Short personality summary paragraph near the top
- A right-side “Character Details” section with structured attributes
- A right-side “Character Description” section with a longer paragraph
- Four image panels showing front view, three-quarter view, side profile, and full body
- Each image panel must have a clear label underneath
- Use clean divider lines and neat spacing
- The sheet should feel like a professional model sheet / design portfolio page / casting reference board

VISUAL STYLE:
- photorealistic
- clean studio lighting
- white or light neutral background
- sharp details
- premium modern presentation
- minimalist editorial graphic design
- black and gray typography
- polished and easy to read

Do not add unnecessary decorative elements.
Prioritize clarity, elegance, readability, and strong identity consistency.
